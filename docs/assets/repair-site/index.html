家具・生活道具の修理相談

壊れ方や素材の名前が分からなくても、全体写真と気になる箇所から相談内容を整理できます。

写真

相談時に確認する三つのこと

修理可否を決める前に、道具の全体、壊れている場所、使い方を確認します。

01 / 写真

全体と破損部

正面だけでなく、裏面、接合部、金具の位置が分かる写真を確認します。

02 / 状態

いつ、どう壊れたか

ぐらつき、欠け、動かないなど、現在の状態と発生したきっかけを確認します。

03 / サイズ

運搬できる大きさか

幅・奥行き・高さと、持ち込みか配送かを決めるための条件を確認します。

預かる前に、作業範囲を決める

  1. 01写真と状態を確認し、修理対象かを判断する。
  2. 02作業内容、交換部品、仕上がりの差を説明する。
  3. 03預かり後に状態を再確認し、変更があれば作業前に連絡する。
  4. 04返却時に、使い方と次回点検する箇所を伝える。

対応範囲を確認後、相談内容を入力できます。
