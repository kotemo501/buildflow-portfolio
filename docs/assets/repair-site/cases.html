状態別の修理例

以下はページ構成と表示を確認するための架空例です。実案件、実績、作業保証を示すものではありません。

椅子 / 接合部

座ると脚がぐらつく

確認する箇所：脚と座面の接合部、過去の接着跡、木部の割れ。対応例：分解できる範囲を確認し、接合部を組み直す。

収納 / 引き出し

引き出しが途中で止まる

確認する箇所：レール、底板、側板のゆがみ。対応例：干渉箇所を確認し、部品交換または調整範囲を決める。

受付の流れを見る
木製品 / 表面

トレイの表面が白くなった

確認する箇所：素材、塗装、洗剤や熱の影響。対応例：目立たない場所で状態を確認し、再塗装の可否を判断する。

扉 / 蝶番

扉の左右がそろわない

確認する箇所：蝶番のゆるみ、取付位置、扉の変形。対応例：金具の状態を確認し、調整か交換かを決める。

受付の流れを見る

全体と細部を、同じ向きで記録する

  • 道具全体が入る写真。
  • 破損部を正面と斜めから写した写真。
  • 裏面、接合部、金具の位置が分かる写真。
  • 定規を添え、傷や欠けの大きさが分かる写真。
