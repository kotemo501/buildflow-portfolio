相談から納品まで

最初に、変える範囲と確認方法を決めます。

  1. 01

    素材と条件を確認

    ページ数、素材の状態、テンプレート、納品形式、確認者を整理します。

  2. 02

    方向を合わせる

    契約後、代表ページまたは構成案で、文字量と見せ方を確認します。

  3. 03

    全体を制作

    合意した方向に沿って制作し、未確定事項は推測で埋めず確認事項として残します。

  4. 04

    確認して納品

    表示、リンク、編集可能性、ファイル構成を確認し、指定形式で渡します。

見積に必要な情報

  • ページ数または画面数
  • 原稿と素材がそろっているか
  • 既存テンプレートやデザイン規則
  • 納品形式と確認方法
  • 希望時期とレビュー担当者

修正の扱い

表示崩れ、誤字、合意した仕様との差は修正します。構成変更、原稿追加、新しいページや機能は追加対応として事前に確認します。回数と期限は案件ごとに決めます。

AI・機密情報

AI利用条件を契約前に確認します。AI利用不可の案件には対応しません。機密情報や個人情報を、許可なく外部AIへ入力しません。
