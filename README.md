# PowerPoint・業務資料・静的Web ポートフォリオ

`kotemo501`名義で公開する、自主制作ポートフォリオです。実案件、受注実績、導入効果を示すものではありません。

## 目的

CrowdWorks等のプロフィールから訪れた発注者が、短時間で次を判断できるようにしています。

- 何を依頼できるか
- どのような入力から制作するか
- 制作時に何を判断するか
- 何が納品されるか
- 修正と追加対応の境界
- 自主制作で確認できること、確認できないこと

## ケーススタディ

1. PowerPoint原稿の整形：6ページ、編集用PPTX、表示確認用PDF
2. 問い合わせ一次対応マニュアル：7ページ、編集用PPTX、表示確認用PDF
3. 工事写真の登録・確認フロー提案：8ページ、編集用PPTX、表示確認用PDF
4. 家具・生活道具の修理受付サイト：HTML／CSS／JavaScriptによる6ページの静的サイト、ソースZIP

PowerPointの表示確認用PDFは、確定したスライド画像から作成しています。文字検索やコピーには向きません。編集にはPPTXを使用します。Windows版Microsoft PowerPointでの実機確認は行っていません。

修理受付サイトの相談画面は入力UIの実装例です。送信、保存、外部通信は行いません。

## 公開構成

- `docs/index.html`：制作例、対応範囲、進行、見積条件、修正境界
- `docs/cases/`：4件のケーススタディ
- `docs/styles.css`：ポートフォリオ共通スタイル
- `docs/assets/case-images/`：入力、判断、完成、引継ぎを示す代表画像
- `docs/assets/`：PPTX、PDF、静的サイト、ソースZIP

GitHub Pagesの公開元は`main`ブランチの`/docs`です。公開ファイルには実名、個人連絡先、実在顧客情報を掲載していません。
